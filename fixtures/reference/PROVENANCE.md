# fixtures/reference — provenance ledger

**A profile is a copyrighted work, and a repository is redistribution**
(`docs/LEGAL.md` §3). Every file in this directory has an entry here
*before* it is added; a fixture of unknown provenance is not a fixture.

Only category (b) profiles — published under terms that explicitly
permit redistribution — may appear here. Category (c) profiles (Windows,
Adobe, vendor installations) are **never committed**; tests read them
from the local system and skip when absent.
